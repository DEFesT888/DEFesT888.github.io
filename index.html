Прогностический подбор доноров

СПАД — программа для ЭВМ, предназначенная для автоматизированного интеллектуального подбора совместимых донорских компонентов крови по антигенному фенотипу эритроцитов реципиента на основе стандартизированной базы данных и методов машинного обучения.

Прокрутите вниз

СПАД реализует гибридный подход: сочетание строгих медицинских правил совместимости с моделью машинного обучения. Время подбора сокращается с нескольких часов до 1–2 минут.

Вкладка 01

Поиск донора

Простой и расширенный режим поиска совместимых донорских компонентов крови

Два режима поиска

Интерфейс поиска донора предоставляет два режима: простой — для быстрого подбора по группе крови и основным антигенам, и расширенный — для детального задания полного фенотипа реципиента.

Функциональность

  • Простой поиск — быстрый подбор по ABO, Rh(D) и ключевым антигенам
  • Расширенный поиск — полная спецификация фенотипа: C, c, E, e, K, k и другие антигены
  • Гибридный ИИ-модуль — сочетание строгих медицинских правил (приоритет ABO, гетерозиготность C/c, E/e, K/k) с ML-моделями
  • Ранжирование — автоматическая сортировка доноров со статусами «Идентичный» и «Совместимый»
  • Процент совпадения — количественная оценка совпадения антигенов для каждого донора

Технологии

Random Forest Logistic Regression SVM (RBF) CustomTkinter

Модели ML

Logistic Regression 86.2%
SVM (RBF) 88.7%
Ансамбль LR+SVM 89.1%
Вкладка 02

История поиска

Журнал всех запросов с возможностью повторного поиска и прослеживаемостью решений

Полная прослеживаемость

Все операции подбора фиксируются в журнале истории поиска, что обеспечивает полную прослеживаемость «донор — компонент — реципиент» и позволяет в любой момент повторить или проанализировать предыдущий запрос.

Функциональность

  • Журнал запросов — хронологический список всех операций подбора с параметрами реципиента и результатами
  • Повторный поиск — возможность повторить любой предыдущий запрос одним кликом
  • Фильтрация — по дате, типу поиска, группе крови, результату
  • Детализация — просмотр полных результатов ранжирования для каждого запроса
  • Экспорт — сохранение истории в PDF для аудита и отчётности

Преимущества

  • Прозрачность решений ИИ
  • Аудит подбора доноров
  • Снижение субъективности
  • Обучение на истории
  • Соответствие 152-ФЗ
Вкладка 03

Статистика БД

Графики распределения доноров, фенотипов и групп крови в реальном времени

Аналитика базы данных

Вкладка статистики предоставляет наглядную визуализацию состояния донорского банка: распределение по группам крови, фенотипам, индекс редкости (rarity_score) и другие ключевые показатели.

Возможности

  • Распределение по группам крови — круговая диаграмма ABO и Rh(D)
  • Фенотипический профиль — распределение антигенов C, c, E, e, K, k
  • Индекс редкости — rarity_score для выявления дефицитных фенотипов
  • Объём базы — общее количество доноров и компонентов крови
  • Обновление в реальном времени — данные актуализируются при каждом добавлении донора

Стандартизация

  • ISBT 128 маркировка
  • ISO 8601 формат дат
  • Нормализация 3НФ
  • Очистка пропусков и дубликатов
  • Производные признаки
Вкладка 04

Карточка донора

Полная информация о доноре: фенотип, HLA, история донаций, добавление новых записей

Управление донорами

Карточка донора объединяет всю информацию о доноре в едином представлении: персональные данные, полный фенотип, результаты HLA-типирования, история донаций и доступные компоненты крови.

Ключевые функции

  • Полный фенотип — ABO, Rh(D), Kell (K/k), Duffy, MNS и другие эритроцитарные антигены
  • HLA-типирование — результаты генетического типирования для расширенного подбора
  • История донаций — полная хронология сдач крови с датами и типами компонентов
  • Добавление доноров — возможность внесения новых записей в базу данных
  • Редактирование — обновление данных донора при изменении статуса или фенотипа

Вкладка 05

PDF-отчёты

Мгновенный экспорт результатов подбора в PDF для медицинской документации и электронных карт

Формирование отчётов

Система генерирует полноценные PDF-документы с результатами подбора доноров, включающие ранжированный список, процент совпадения антигенов, клинические рекомендации и данные реципиента.

Возможности

  • Результаты подбора — ранжированный список доноров с процентом совпадения и статусом
  • Медицинская документация — формат, соответствующий требованиям службы крови
  • Клинические рекомендации — автоматически генерируемые рекомендации на основе ИИ-анализа
  • Статистика БД — отчёты по распределению доноров, фенотипов, групп крови
  • Мгновенный экспорт — формирование PDF за секунды без дополнительного ПО

Содержание отчёта

  • Данные реципиента
  • Ранжированный список доноров
  • Статус: Идентичный/Совместимый
  • Процент совпадения антигенов
  • Клинические рекомендации
  • Дата и время формирования

Технологии и безопасность

Кроссплатформенное приложение соответствия 152-ФЗ, псевдонимизация, шифрование данных

Технический стек

СПАД разработана как кроссплатформенное приложение на Python с использованием современных библиотек машинного обучения и графического интерфейса CustomTkinter.

Ключевые технологии

  • Python — основной язык разработки, единая кодовая база для всех платформ
  • MySQL + SQLAlchemy — реляционная база данных с ORM-фреймворком
  • scikit-learn — библиотека ML: Logistic Regression, SVM, Random Forest
  • CustomTkinter — современный графический интерфейс, 5 вкладок
  • Стандарт ISBT 128 — международная маркировка компонентов крови

Кроссплатформенность

  • Microsoft Windows 10/11 — полная поддержка, тестирование завершено
  • Linux (ядро 3.10+) — Ubuntu 22.04 и совместимые дистрибутивы
  • macOS 13+ — поддержка Intel и Apple Silicon (ARM64)
  • Архитектуры — x86_64, ARM64, ppc64le, s390x

Безопасность

  • Соответствие 152-ФЗ
  • Псевдонимизация данных
  • Шифрование хранения
  • Врачебная тайна
  • Аудит операций
